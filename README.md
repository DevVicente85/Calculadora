# **Calculadora Simples em JavaScript**

Uma aplicação de calculadora limpa, moderna e responsiva, desenvolvida sem o uso de frameworks, focada em boas práticas de manipulação do DOM e lógica de programação pura.

---

**Funcionalidades**

- Operações aritméticas básicas (Soma, Subtração, Multiplicação e Divisão).
- Funções avançadas e auxiliares (Porcentagem, Inversão de Sinal `+/-`, Limpar `C` e Apagar último dígito `⌫`).
- Suporte total ao teclado (Atalhos para operadores, Enter, Backspace e Esc).
- Design minimalista com alinhamento otimizado via CSS Grid.
- Tratamento robusto de erros (Divisão por zero e múltiplas vírgulas).

---

**Tecnologias Utilizadas**

- HTML5 (Estruturação semântica)
- CSS3 (Grid Layout e Design Responsivo)
- JavaScript (Lógica de estado, manipulação de eventos e teclado)
